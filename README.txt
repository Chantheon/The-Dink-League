DINK LEAGUE V3 — COMPLETE DOUBLE-ELIMINATION PROGRESSION

Upload these five files to the root of a GitHub repository:
index.html
manifest.json
sw.js
icon-192.png
icon-512.png

Enable GitHub Pages:
Settings > Pages > Deploy from branch > main > /(root) > Save.

Open the Pages URL in Safari on iPhone > Share > Add to Home Screen.

V3 features:
- Doubles teams (2 players)
- Best of 3 or Best of 5
- Round robin: every team plays every other team once
- Automatic season standings and seeding
- Top 8 playoff bracket
- Winners bracket progression
- Losers bracket progression after each loss
- Two-loss elimination
- Grand final
- Grand-final reset if the undefeated winners-bracket team loses its first championship match
- 3rd-place match
- Automatic 1st / 2nd / 3rd place results
- Local device storage

This is still a free PWA, not an App Store binary. Cloud syncing/accounts can be added later.
