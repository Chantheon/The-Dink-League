DINK LEAGUE — FREE IPHONE INSTALL

This is a free, installable web app (PWA). Your league data is stored locally on the device.

To install on iPhone:
1. Put these files on any HTTPS web host. A free option is GitHub Pages.
2. Open the site in Safari on your iPhone.
3. Tap Share.
4. Tap "Add to Home Screen".
5. Name it "Dink League" and tap Add.

IMPORTANT:
- Data is currently stored locally in the browser/device.
- This first version does not have cloud accounts or multi-device syncing.
- For a true App Store app and shared league data, the next version should add a cloud database and user accounts.
